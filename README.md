# Distributor Offline installers

Download and run the installer:

- [MSI installer](https://github.com/NazeemSource/Distributor-Offline-Installer/releases/latest/download/SH.DistributorOffline-win.msi) (machine-wide)
- [Setup EXE](https://github.com/NazeemSource/Distributor-Offline-Installer/releases/latest/download/SH.DistributorOffline-win-Setup.exe) (per-user)

The application source code and the token-protected update feed are kept in a private repository. In the application, open the version label to add a GitHub token once and receive future delta updates.
